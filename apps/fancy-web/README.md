# Fancy Web

Frontend Angular para o encurtador de URLs `fancy`.

## Development Server

Na raiz do repositório, inicie o servidor de desenvolvimento com:

```bash
make web-boot
```

Quando o servidor estiver rodando, acesse `http://localhost:4200/`. A aplicação recarrega automaticamente ao modificar os arquivos.

## Build

Na raiz do repositório, gere o build de produção com:

```bash
make web-build
```

Os artefatos são gerados em `apps/fancy-web/dist/`.

## Tests

Na raiz do repositório, execute os testes do frontend com:

```bash
make web-test
```
